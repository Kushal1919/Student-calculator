# Student Calculator

A simple Java console-based Student Calculator project.

## Features

- Enter student name
- Enter number of subjects
- Enter marks for each subject
- Calculate total marks
- Calculate average
- Calculate percentage
- Calculate grade
- Check pass/fail result
- Find highest mark
- Find lowest mark

## Technologies Used

- Java
- Scanner
- Arrays
- For Loops
- If-Else Statements

## How It Works

The program takes the student's name, number of subjects, and marks as input.

It then calculates:

- Total marks
- Average
- Percentage
- Grade
- Pass/Fail
- Highest mark
- Lowest mark

## Grade System

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| Below 50   | F     |
